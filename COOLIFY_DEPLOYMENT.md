## Required environment variables

Set these in **Coolify → Visitor Flow → Environment Variables**.

The two `VITE_` variables must have **Build Variable** enabled because Vite embeds them into the browser bundle. Coolify may also leave Runtime enabled.

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

If a server-side feature imports `supabaseAdmin`, also add the service-role key as a **Runtime-only secret**:

```env
SUPABASE_SERVICE_ROLE_KEY=YOUR_SUPABASE_SERVICE_ROLE_KEY
```

Never expose the service-role key through a `VITE_` variable.

## DNS

Point the subdomain at the same Coolify server:

```text
A  vms  95.111.234.34
```

Then configure the Coolify application domain as:

```text
https://vms.owltechsolutionsltd.com
```

## Supabase Auth

In Supabase Auth URL Configuration, allow Visitor Flow redirects from:

```text
https://vms.owltechsolutionsltd.com/**
```

This is required for sign-up verification and authentication redirects.

## Auto deploy

Enable **Auto Deploy** in Coolify and configure the GitHub push webhook generated by Coolify for the `main` branch. Every push or merge to `main` will then rebuild and redeploy Visitor Flow automatically.
